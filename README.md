# Soldier Security Services Ltd. (SSSL) — Corporate Web Platform

Official production-grade corporate website for **Soldier Security Services Ltd.** (Incorporation Reg. No: **C-96185/11**, Date of Registration: **16.10.2011**), a private security service provider operating in Bangladesh.

---

## 🛡️ Project Overview

* **58 Verified Client Deployments:** Integrated directly from the official company profile roster spanning industrial apparel plants (RMG), Export Processing Zones (DEPZ Ganakbari), packaging industries, agricultural estates, and commercial towers.
* **Official Document Access:** Direct one-click download for the authentic 6-page official company profile PDF (`/documents/soldier-security-services-profile.pdf`).
* **Direct Liaison & Quotation Gateway:** Multi-step validated security request form with instant prefilled WhatsApp dispatch (`+8801707059684`) and direct 24/7 hotline integration (`01707059684`).
* **Executive Leadership:** Official director profiles for Chairman Sabina Yasmin and Managing Director Md. Kamal Hossain.
* **Animation & Interaction:** Hardware-accelerated GPU cursor spotlight in hero, restrained magnetic button physics, momentum touch swipe for project carousels, and reduced-motion accessibility.
* **Compact Brand Header:** Clean 72px desktop / 64px mobile navbar with the uncropped official logo emblem.

---

## 🚀 Tech Stack

* **Core:** React 19 + TypeScript + Vite 5
* **Styling:** Tailwind CSS + PostCSS + Autoprefixer
* **Icons:** Lucide React
* **Motion & Animations:** Framer Motion + Hardware-accelerated GPU transforms

---

## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/ShahriarLabs/sssl-website.git
cd sssl-website

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
